# Creative Programming

Real answers to real C++ programming problems, written from production experience.

This repository contains articles written in response to questions from developers working in C++, audio programming, JUCE, and creative tool development. Code examples are drawn from real production codebases — not toy examples.

- **JUCE Framework** — components, timers, audio graphs, UI patterns
- **Creative Software Architecture** — NLE editors, DAW design, cross-app interop
